# Source photographs

The pictures in [`../pictures`](../pictures) are converted from these
photographs. **The originals are not committed.** They're full-resolution
stock photographs, and redistributing them here would say something about
their licensing that isn't ours to say.

To regenerate the pictures, put these files in this folder and run
`src/image4k/tools/pictures.sh`:

| File | Original | Source |
| --- | --- | --- |
| `balloons.jpg` | `landscape-morning-fog-mountains-with-hot-air-balloons-sunrise.jpg` | Freepik |
| `braies.jpg` | `pietro-de-grandi-T7K4aEPoGGk-unsplash.jpg` | Unsplash — Pietro De Grandi |
| `spectrum.jpg` | `3d-geometric-abstract-background.jpg` | Freepik |

Any resolution and aspect works: the converter crops to fill and resizes.
